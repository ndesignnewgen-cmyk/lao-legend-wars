# ແຜນໜ້າກາດໃໝ່ · ຈຸດບັນທຶກ 05/11/2026

## ຂໍ້ຕົກລົງລ່າສຸດ

ເຈົ້າຂອງຂໍ commit ແຜນ ແລະຕົວຢ່າງໄວ້ກ່ອນ ເພື່ອເຮັດຕໍ່ຄັ້ງໜ້າ.
ຮູບອ້າງອີງລ່າສຸດແມ່ນ Screenshot 2026-11-05 at 12.09.06.png.
ຍຶດຂໍ້ຕົກລົງຂ້າງລຸ່ມນີ້ແທນການລອງແບບເກົ່າ.

1. **ທຸກອາດໃຊ້ກ່ອງແບບອາດພິເສດໃນຮູບ**: ບຸນກ່ອງແດງຕົວເລກຂາວ, ພະລັງຫົວແດງພື້ນຂາວ, ຊື່ຢູ່ປ້າຍຄຳຕັດມຸມ. ປົກກະຕິ ແລະອາດພິເສດໃຊ້ຮູບແບບດຽວກັນ. ກາດທີ່ບໍ່ແມ່ນຕົວລະຄອນຍັງບໍ່ມີພະລັງ.
2. **ປ້າຍຮ່ວມຮ່າງສີມ່ວງ**: ຍ້າຍຈາກກ້ອງບຸນຂຶ້ນມາຂ້າງຂວາຂອງບຸນ. ຫຍໍ້ລົງປະມານ 20%; ມີຮູບຮ່ວມຮ່າງ ແລະເລກ 2/3 ບອກຈຳນວນກາດ. ປ້າຍປະເພດ/ວິທີອັນເຊີນອື່ນຢູ່ຕຳແໜ່ງດຽວກັນ.
3. **ຂໍ້ຄວາມສະກິນແບບເກົ່າ**: ຮັກສາຟອນ, ການຕັດແຖວຕາມທຳມະຊາດ, ປ້າຍຄຳສຳຄັນ ແລະສີເດີມຈາກ fmtSkill. ອາດປົກກະຕິມີກ່ອງສະກິນສີອ່ອນ; ອາດພິເສດຂໍ້ຄວາມລອຍສີເຂັ້ມຂອບຂາວ ບໍ່ມີກ່ອງສະກິນ.
4. **ອາດພິເສດຮູບເຕັມ**: ຂອບເສັ້ນບາງທີ່ສຸດ; face inset 0.18 cqw. ປ້າຍຊື່ຄຳຍັງມີຄືທຸກອາດ.
5. **ໂລ້ເຜົ່າທີ່ອະນຸມັດ**: 7.8 × 9 cqw, ເຜົ່າທີສອງລຽງລົງລຸ່ມຫ່າງ 0.8 cqw. ຮັກສາຮູບສັນຍາລັກເດີມ.
6. **ສີຕ້ອງມີປ້າຍຊື່/ຮູບນຳ**: ແຍກປະເພດກາດ, ວິທີອັນເຊີນ ແລະຄວາມຫາຍາກໃຫ້ເຂົ້າໃຈ. ບໍ່ປ່ຽນປະເພດກາດຈິງ ຫຼືກົດອັນເຊີນເພາະສີ.
