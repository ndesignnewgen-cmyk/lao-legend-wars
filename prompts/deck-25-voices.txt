ເດັກ 25 · ໝໍຜີ ອາຈານແດງ · ສຽງພາກຕົວລະຄອນ ຕອນລົງສະໜາມ (16 ໄຟລ໌)
ເກມຈະເປີດສຽງນີ້ ຕອນກາດລົງສະໜາມ. ຄຳເວົ້າສັ້ນ 1–2 ວິນາທີ.

=====================================================================================================
ເຮັດຢູ່ໃສ: ElevenLabs (elevenlabs.io)
=====================================================================================================
ຂັ້ນ 1 · ສ້າງສຽງຕົວລະຄອນ (ເຮັດເທື່ອດຽວຕໍ່ຕົວ)
  1. ເຂົ້າ elevenlabs.io → ເມນູຊ້າຍ Voices → ກົດ "+ Create a Voice" → ເລືອກ "Voice Design".
  2. ກັອບຂໍ້ຄວາມ VOICE (ພາສາອັງກິດ) ຂອງຕົວນັ້ນ ໄປວາງໃນຊ່ອງ "Describe the voice".
  3. ກົດ Generate → ຟັງ 3 ສຽງທີ່ອອກມາ → ເລືອກສຽງທີ່ມັກ → Save → ຕັ້ງຊື່ຕາມຊື່ໄຟລ໌ (ajandaeng …).

ຂັ້ນ 2 · ໃຫ້ສຽງນັ້ນເວົ້າ
  1. ເມນູຊ້າຍ Text to Speech → ເລືອກສຽງທີ່ Save ໄວ້ → Model ເລືອກ "Eleven v3".
  2. ກັອບ LINE (ພາສາລາວ) ໄປວາງ. ຄຳໃນວົງເລັບ [ ] ເຊັ່ນ [giggles] ແມ່ນບອກອາລົມ, ວາງໄປນຳໄດ້ເລີຍ.
  3. ກົດ Generate → ຟັງ → ກົດດາວໂຫຼດ (MP3) → ຕັ້ງຊື່ໄຟລ໌ຕາມ [ຊື່] ຂ້າງລຸ່ມ (ເຊັ່ນ ajandaeng.mp3).

ຖ້າ AI ອ່ານພາສາລາວບໍ່ຖືກ (ສຽງເພີ້ນ):
  ໃຊ້ Voice Changer ແທນ: ເມນູຊ້າຍ Voice Changer → ເລືອກສຽງຕົວລະຄອນ → ກົດໄມ ແລ້ວອັດສຽງເຈົ້າເອງ ເວົ້າປະໂຫຍກນັ້ນ
  ໃຫ້ມີອາລົມ → Generate. ມັນຈະປ່ຽນສຽງເຈົ້າ ເປັນສຽງຕົວລະຄອນ ແຕ່ຄຳເວົ້າລາວຍັງຖືກຕ້ອງ.
  ຫຼື ອັດສຽງໝູ່ ໃນໂທລະສັບເລີຍກໍ່ໄດ້ (Voice Memos). ສົ່ງ m4a ມາກໍ່ໄດ້.

ສົ່ງ: ໃສ່ທຸກໄຟລ໌ໃນ voices.zip ແລ້ວສົ່ງໃນແຊັດ. ຖ້າເລືອກບໍ່ໄດ້ ສົ່ງ 2 ອັນມາ (ajandaeng-a.mp3, ajandaeng-b.mp3).
ສຽງດັງຄ່ອຍບໍ່ເປັນຫຍັງ, ຂ້ອຍຈະປັບໃຫ້ເທົ່າກັນ ແລະ ຕັດຊ່ວງງຽບອອກເອງ.
ລິຂະສິດ: ແຜນຟຣີຂອງ ElevenLabs ໃຊ້ໄດ້ສະເພາະບໍ່ຫາເງິນ. ເກມມີຮ້ານຂາຍເພັດ, ສະນັ້ນ ຕອນເຮັດສຽງແທ້ໃຫ້ໃຊ້ແຜນເສຍເງິນ.
